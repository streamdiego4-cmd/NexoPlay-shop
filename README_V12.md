# NexoPlay V12

Ajuste final solicitado sobre la versión V11.

## Cambios
- El bloque superior de confianza ahora habla del servicio: Atención personalizada, Pagos seguros, Entrega ágil y Soporte posventa.
- El perfil para escritorio ocupa mejor el ancho disponible y reduce altura sin modificar el resto del catálogo.
- El perfil usa el alto real de la ventana y mantiene las acciones del pie visibles sin depender de F11.
- En móvil se conserva el diseño responsive y el pie de acciones queda accesible.

No se eliminan módulos de negocio ni se modifica la lógica de compras, Wallet, rangos, ventas o soporte.
